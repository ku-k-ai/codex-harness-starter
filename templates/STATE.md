# 現在の状態

再開に必要な現在地を短く保つ。終了時は `done` / `blocked` / `budget` のどれかを記録する。進行中は `working`。

- 状態: working
- 更新日時・タイムゾーン: [記入]
- 対象ブランチ/コミット・未コミット差分: [記入]
- 検証済みの状態: [コミット/差分と実行結果の参照先]
- 現在の作業版との違い: [検証後に変更したもの。なければ「なし」]
- 完了条件: [A1=未確認、A2=未確認、M1=未確認 など]
- 確認済みの事実: [判断に必要なものだけ]
- 今の仮説と次の一手: [記入]
- 未解決・再開条件: [なければ「なし」]
- 残り予算/消費状況: [測定できる範囲。推定なら明記]

コマンドが成功したことと、全要件が満たされたことを分ける。再開時は実際の差分と最新結果を照合し、このメモだけを現在の事実と決めつけない。
